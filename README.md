# 🚀 Sistema Completo de Cadastro e Login

## 🎯 Objetivo
Criar um sistema web completo que simula cadastro, login, sessão ativa e área protegida, incluindo funcionalidades extras como perfil, tarefas e dark mode.

## 🧩 Tecnologias usadas
- HTML
- CSS (inclui Dark Mode)
- JavaScript (LocalStorage)
- Deploy: Netlify

## 🚀 Funcionalidades
- Cadastro de múltiplos usuários (nome, email, senha, foto)
- Validação de duplicados
- Login com sessão ativa
- Logout
- Dashboard protegido
- Perfil do usuário (nome e foto)
- Sistema de tarefas (To-Do List)
- Estatísticas básicas
- Tema escuro/claro (Dark Mode)
